# quanttide-relation

量潮公共关系

## 概述

quanttide-relation 是量潮公共关系领域，围绕对外传播、媒体关系与公共事务，沉淀领域第二大脑。

## 领域边界

- **对外传播**：面向公众与媒体的信息输出、口径与叙事
- **媒体关系**：媒体渠道、采访与合作关系的维护
- **公共事务**：与外部机构、社区和公众的公共议题应对
- **声誉管理**：舆情观察与声誉维护

## 子模块

| 路径 | 说明 |
|------|------|
| `data/context` | 公共关系语境 (git submodule → quanttide-context-of-public-relations) |
| `data/journal` | 公共关系日志 (git submodule → quanttide-journal-of-public-relations) |
| `data/archive` | 公共关系档案 (git submodule → quanttide-archive-of-public-relations) |
| `data/brochure` | 公共关系宣传册 (git submodule → quanttide-brochure-of-public-relations) |
